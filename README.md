# 🌐 Personal Portfolio | كيان النزاري

An interactive, minimalist, and fully responsive dual-language (Arabic & English) personal portfolio website. Designed and built from scratch to showcase the intersection of **Digital Marketing Strategy** and **Software Engineering**.

---

## ✨ Features | المميزات

- 🌐 **Bilingual Support (العربية / English):** Seamless toggle between Arabic (RTL) and English (LTR) layouts.
- 🎨 **Minimalist & Clean Aesthetic:** Focused on readable design, strong typography, and effective visual hierarchy.
- 📱 **Fully Responsive:** Optimized for viewing across Mobile, Tablet, and Desktop screens.
- ⚡ **Lightweight & High Performance:** Built using pure HTML5 and modern CSS3 without heavy external dependencies.

---

## 🛠️ Tech Stack | التقنيات المستخدمة

- **Structure:** HTML5
- **Styling & Layout:** CSS3 (Flexbox & CSS Grid)
- **Version Control:** Git & GitHub
- **Deployment:** GitHub Pages
